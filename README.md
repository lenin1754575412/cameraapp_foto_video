# Cámara y video (basado en cameraapp.rar)

Esta versión conserva la estructura y versiones de Expo del proyecto que enviaste.

## Instalar en VS Code / PowerShell

1. Abre esta carpeta nueva, no la carpeta anterior.
2. `npm install`
3. `npx expo install expo-video`
4. `npx expo start -c`

La dependencia expo-video se instala mediante Expo para elegir automáticamente la versión compatible con SDK 58.

Funciones: cámara frontal/trasera, tomar fotos, grabar/detener videos con audio y reproducir video.
Las fotos y videos no se guardan automáticamente en la galería.

Si aparece algún error, comparte el resultado de la terminal.
